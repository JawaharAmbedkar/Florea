# 💎 Floréa — Fine Luxury & Lab Diamond Jewelry E-Commerce

**Floréa** is a high-end, editorial e-commerce experience for luxury fine jewelry and ethical lab-grown diamonds. The interface combines elegant visuals, fluid motion, and a responsive shopping experience designed for modern luxury retail.

---

## ✨ Features

- 💍 Curated collections and editorial layouts for pieces such as the Aurora Petal Collection and Trending Style.
- 🖼️ Responsive hero carousel with layered storytelling and featured product cards.
- 🔍 Dynamic catalog browsing with category-based product discovery.
- 🛒 Interactive slide-out cart with quantity updates and checkout flow.
- 📱 Fully responsive layout for desktop and mobile shopping experiences.
- 🎨 Editorial visual language with warm typography, rich imagery, and polished motion.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React Icons
- **Animations**: Motion (`motion/react`)
- **State Management**: React Hooks and local UI state

---

## ▶️ Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key.
3. Start the development server:
   `npm run dev`
