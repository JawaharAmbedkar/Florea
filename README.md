# 💎 Floréa — Fine Luxury & Lab Diamond Jewelry E-Commerce

**Floréa** is a high-end, editorial e-commerce application crafted for luxury fine jewelry and ethical lab-grown diamonds. Designed with an elegant aesthetic, fluid animations, and responsive UI components.

---

## ✨ Features

- 💍 **Curated Collections & Editorial Layouts**: Highlight bespoke collections such as the *Aurora Petal Collection* and *Editor's Pick Trending Style*.
- 🖼️ **Responsive Hero Carousel**: Interactive image carousel with overlay hero copy and inset shop cards tailored for all screen sizes.
- 🔍 **Dynamic Catalog & Filtering**: Filter fine jewelry by categories (Engagement, Wedding Bands, Gemstones, Fine Jewelry) and sub-categories.
- 🛒 **Interactive Slide-Out Cart**: Fast cart drawer with instant quantity updates, free shipping progress bar, and checkout flow.
- 📱 **Fully Responsive**: Desktop-first and mobile-optimized layouts with touch-friendly navigation.
- 🎨 **Editorial Aesthetic**: Warm neutral typography pairings, high-contrast imagery, and smooth Motion animations.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React Icons
- **Animations**: Motion (`motion/react`)
- **State Management**: React Hooks & Context
